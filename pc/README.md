# 简传 Lite

局域网内传文件、传文字的小工具。同一 WiFi 下，手机、平板、电脑打开同一个网址就能互传，文件不经过任何云服务器。

## 怎么用

1. 双击 **启动.bat**
2. 浏览器会自动打开 `http://127.0.0.1:8787`
3. 右侧显示局域网地址（形如 `http://192.168.x.x:8787`），手机连同一个 WiFi 后在浏览器里输入它
4. 拖文件进来、粘贴图片、或者直接打字

关掉黑色命令行窗口 = 停止服务。

## 功能

| 功能 | 说明 |
|---|---|
| 发文本 | Enter 发送，Shift + Enter 换行，自动识别链接 |
| 发文件 | 拖拽 / 点击回形针 / 直接 Ctrl+V 粘贴，单文件最大 4GB |
| 图片预览 | 自动生成缩略图，点开看大图，右下按钮下载原文件 |
| 多设备同步 | 1.2 秒轮询，任何设备发的消息所有设备都能看到 |
| 明暗主题 | 左下角月亮/太阳按钮切换 |
| 二维码 | 右侧地址旁的方形按钮，扫码直达（需联网生成图片） |
| 历史记录 | 存在 `data/` 目录，重启不丢；保留最近 1500 条 |

## 文件结构

```
lan-transfer/
├── 启动.bat          双击启动
├── server.py         后端（Python 标准库，零依赖）
├── static/
│   └── index.html    前端页面
└── data/
    ├── messages.json 消息记录
    └── files/        实际文件
```

## 常见问题

**手机打不开？**
- 确认同一个 WiFi（手机别开流量，电脑别连有线不同网段）
- 首次启动 Windows 弹出防火墙提示要点「允许访问」
- 路由器开了「AP 隔离 / 客户端隔离」时，设备之间互相访问不了，需要关掉

**命令行窗口一关就断了？**
正常，服务就跑在那个窗口里。想后台常驻可以做成计划任务。

**端口被占用？**
会自动往后找（8787 → 8788），以窗口里打印的地址为准。

## 安全提醒

这是纯局域网工具，**没有密码**。同一网络里的任何人都能打开页面、看到所有消息和文件。不要在公共 WiFi（咖啡厅、公司访客网）里用，别传密码、证件这类东西。
